# 魔女：狂猎 · 卡牌图鉴

卡牌图鉴、规则中枢与角色世界观网站。卡牌数据来自用户提供的 V4 表格；规则来自 V4 规则书。

## 内容

- 基础牌305张、禁咒38张、诡计52张、悬赏30张、茶会22张、魔神殿9座、魔女角色32位，共488条。
- 规则书中的“5张悬赏”指每局随机展示数量，图鉴保留完整30张牌库。
- 原表不包含卡图；规则书13条匹配记录附教学示例。正式卡图可由管理员上传。
- 未提供的角色背景、配件及设计备注留待补充；世界观只使用已知资料。
- 背景为原创氛围插画，不是正式游戏主版图。

## 管理员

进入 `/admin`。邮箱验证码只向 `1484052217@qq.com` 发送，服务器独立校验身份；只有管理员有权读取草稿、上传图片和保存发布。启用方式见 [邮箱配置说明](EMAIL_LOGIN_SETUP.md)。发信服务未配置时拒绝登录，不接受外部身份标头授予的编辑权限。

1. 搜索并选择卡牌，或选择“新增卡牌”。
2. 编辑效果、字段、描述和图片。
3. “保存草稿”将修改保存在云端，访客继续看到已发布内容。
4. “发布卡牌”保存并公开当前版本。访客再次访问、切回页面或自动刷新后能看到更新。

图片支持PNG、JPG、WebP和GIF，最大8MB。未发布图片只允许管理员读取。管理员在多个窗口同时编辑时，过期版本会被拒绝；载入最新草稿前可确认是否放弃本地未保存修改。

后台的“规则文章”“世界观文章”“角色文章”支持新增条目、编排段落与章节标题、上传图片与图片说明。角色文章须选择所属魔女，发布后显示在对应角色详情中。文章和展示参数均支持先保存草稿，再发布。

“展示参数”可调整每类卡牌的高度、宽度、圆角、侧栏图宽，以及流光、雾气和动效。默认尺寸按高度×宽度：基础/禁咒/诡计88×63、悬赏52×43、茶会122.5×63、魔神殿172×59.5、角色145×83（毫米）。卡图以cover填充并裁切圆角；每张卡牌可单独调整图片横向、纵向位置与缩放。

规则已按设计者确认修订：初始手牌上限5；各玩家在每座魔神殿按1至8层逐层供奉一次，到顶可继续爬虚拟层数并记作第8层；错过触发的诡计移出游戏；卡牌文本优先，未注明的遵循基础规则；清除至高天区域规则，保留“至高天心锁”卡名与效果。

## 开发与存储

Vinext / React，Cloudflare Worker，D1保存卡牌、文章和展示参数的草稿与发布版本，以及验证码和会话的哈希记录；R2保存上传图片。默认部署到自有 Cloudflare 账户，完整步骤见 [Cloudflare 部署说明](CLOUDFLARE_DEPLOY.md)。站点公开浏览，后台独立校验管理员身份。

- `npm run dev`：本地预览。
- `npm run build`：生成服务器和客户端发布包。
- `npm run db:generate`：生成结构迁移。
- `npm run deploy`：应用远程 D1 迁移并部署构建产物。
- 迁移保存在 `drizzle/`，由 `npm run db:migrate:remote` 应用。
- 本地`.env`不会打包上线。线上邮件密钥保存在 Cloudflare Worker Secrets，密钥不进入源代码。
- 初始数据在`data/cards.json`；上传后的编辑保存在D1，不会因重新发布网站源代码而丢失。

## 卡牌编号与字段

七类原始卡牌分别从0001连续编号（例如`basic-0001`）。新增卡牌保存时按所在类别继续分配编号，避免并发创建时重复。旧编号与新编号存在重叠，旧收藏链接需要按新编号更新。

所有卡牌显示来源为“寰宇智识院·第4宇宙泡·坐标377-3-1189-7-90·玛纳海姆·类型·编号”。原始表格行号只保留为内部追溯元数据。

前台字段速览与后台编辑使用同一类别字段清单。角色可选择基础包、扩展1、扩展2、扩展3、扩展4；尚未提供的归属保留为未标注。效果类型包含原有六项，以及禁咒、诡计、悬赏、茶会、角色。

`0002_dusty_rockslide.sql`只增加迁移标记和写入保护结构；卡牌编号数据更新在`lib/catalog-migration.ts`中通过一次事务完成。它同步卡牌主键、草稿和已发布编号，以及文章的角色关联，保留原有内容、图片、修订号和发布时间。编号版本校验及数据库写入计数防止上线期间旧页面或旧服务误写其他卡牌。不要删除迁移标记或重复运行旧编号导入。
