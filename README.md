# 魔女：狂猎 · 静态卡牌图鉴

基于 `z1484052217-ux/Witch-Wild-Hunt` 原界面，改为 Next.js 原生静态导出。发布内容只有 HTML、CSS、JavaScript 与图片，无图鉴 API、数据库、登录或上传服务。

- 图鉴：`https://witchwildhunt.top/`；游戏：`https://game.witchwildhunt.top/`。上线状态见 `DEPLOYMENT.md`。
- 使用公网 **0.3.111** 的 488 张主卡、6 张公开配件、32 位魔女、36 页规则书。基础牌页的 311 项包含 6 张配件，配件不加入普通基础牌堆。
- 卡图复用游戏素材，9 座神殿沿用游戏的分层图片。效果、技能、茶会、悬赏、神殿与 FAQ 来自公开游戏接口。
- 保留原图鉴的 488 个卡牌 URL；五处改名／替换条目显示现行内容，旧名仍可搜索。
- 按用户要求，右上角不显示“进入网页游戏”按钮。
- 原在线管理员编辑、邮箱验证和上传入口已移除。更新内容需要重新构建，不自动跟随游戏更新。

## 本地使用

使用 Node.js 22.13 或更新版本：

```sh
npm install
npm run build
npm run verify:static
npm start
```

预览为 `http://127.0.0.1:5180/`，开发用 `npm run dev`。`out/` 是完整发布目录，正常浏览无需 Node.js。没有自动发布、数据库迁移或清理云资源的 npm 命令。

## 来源与维护

`data/cards.json` 保存当前卡牌及旧路由 ID；`game-catalog.json` 保存公开接口快照；`rule-articles.json` 保存 36 页完整规则；`game-source.json` 记录来源版本、运行提交、逐牌映射和 1,524 个素材的 SHA-256。没有导出账号、私有草稿或对局数据。

更新前保留恢复副本，显式指定已发布游戏提交与对应公开图鉴快照：

```sh
node scripts/import-game.mjs <游戏工作区> <40位已发布提交> <公开图鉴JSON>
npm run build
npm run verify:static
```

导入时校验图片指纹和版本；编号或素材不明确时中止。历史 V4 来源文件保留作追溯，界面已改用现行游戏数据。

## 验证边界

静态验证覆盖 529 个公开页面路径、494 个卡牌对象、36 页规则和全部复制素材。Chrome 1280／390px 定向检查覆盖搜索、旧名、详情、图片可见面积、空结果、断网后的文字筛选、角色深链、规则表格和跨页跳转，并检查零图鉴 API 请求。

实体手机、Safari、完整游戏回归和 250 局批测未执行。没有改变游戏规则或数据库结构。
